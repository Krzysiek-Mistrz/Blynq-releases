# Blynq Releases

This repository hosts the binary releases of Blynq, a cross-platform
local network synchronization utility.

These binaries are primarily used to package Blynq for distribution
networks such as Flathub.

## About Blynq

Blynq is a lightweight utility designed for seamless workflow
synchronization across your local network. It supports desktop systems
(Linux and Windows) as well as mobile devices (Android).

### Features

- Clipboard Sync: Real-time sharing of clipboard history between all
connected devices.
- Shared Snippets: Create text snippets on one device and access them on
any other device on the network.
- Remote Control: Control media playback, volume, and power states (such
as sleep, restart, and shutdown) between your devices.
- File Transfer: Asynchronous local network file transfer for files up to
50MB.
- Smart Discovery: Automatic local network device discovery.

## Usage

To use Blynq on Linux, you can install it via Flatpak. For other
platforms or manual installations, please refer to the main repository.
